## 🛡️ 3. Justification des permissions (Exigée par Google)

Lorsque Google vous demandera d'expliquer pourquoi l'extension utilise chaque permission, copiez-collez ces explications :

* **`bookmarks`** : Nécessaire pour lire l'arborescence des favoris de l'utilisateur, permettre leur recherche instantanée, leur réorganisation et l'ajout de nouveaux favoris.
* **`tabs`** : Utilisé pour ouvrir les favoris sélectionnés dans un nouvel onglet, détecter la page en cours d'affichage lors de l'ajout rapide, et afficher la liste des onglets ouverts dans le gestionnaire de session.
* **`sidePanel`** : Nécessaire pour afficher le panneau latéral natif de Chrome sur le côté de l'écran lors du raccourci clavier `Alt + B`.
* **`storage` / `unlimitedStorage`** : Permet de mémoriser localement les réglages de personnalisation (thème, raccourcis rapides, dossiers pliés, fond d'écran).
* **`favicon`** : Utilisé pour afficher les icônes officielles des sites web en face de chaque favori pour une reconnaissance visuelle immédiate.
